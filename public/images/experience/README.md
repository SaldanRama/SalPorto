# Dokumentasi Folder Gambar Pengalaman (Experience Images)

Folder ini dirapikan khusus untuk menyimpan aset dokumentasi kegiatan untuk setiap Pengalaman (Experience) Saldan Rama.

## Struktur Direktori:

```
public/images/experience/
├── 01-lab-assistant/
│   ├── image-1.webp / .jpg / .png  (Dokumentasi Praktikum / Mentoring)
│   ├── image-2.webp / .jpg / .png  (Sesi Code Review / Modul)
│   └── image-3.webp / .jpg / .png  (Presentasi Lab / Kelas)
│
├── 02-diskominfo/
│   ├── image-1.webp / .jpg / .png  (Desain UI/UX Web Kelurahan Cantik)
│   ├── image-2.webp / .jpg / .png  (Wireframing & Prototyping)
│   └── image-3.webp / .jpg / .png  (Kolaborasi Tim & Implementasi Front-End)
│
└── 03-bpjs-kesehatan/
    ├── image-1.webp / .jpg / .png  (Validasi & Rekonsiliasi Data Faskes)
    ├── image-2.webp / .jpg / .png  (Sistem Pengarsipan Digital Administrasi)
    └── image-3.webp / .jpg / .png  (Operasional Pelayanan & Laporan Berkala)
```

## Panduan Penambahan Gambar Baru:
1. Format yang disarankan: `.webp`, `.jpg`, atau `.png` (rasio aspek 4:3 atau 16:10).
2. Anda dapat langsung menambahkan foto dokumentasi asli Anda ke dalam folder masing-masing.
3. Path gambar dapat dikonfigurasi melalui data `mockExperiences` di `src/data/mockData.js`.
