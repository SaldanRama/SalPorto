# Saldan Rama — Personal Portfolio Website

Personal portfolio website of **Saldan Rama**, Information Systems graduate from Universitas Hasanuddin and creative technologist specializing in **UI/UX Design**, **Front-End Engineering**, and **Graphic Design**.

Built with an editorial aesthetic inspired by high-end design studios, featuring 3D interactive orbital halo mechanics, dynamic typography, and full light/dark mode support.

---

## ✨ Features

- **3D Interactive Hero Halo:** Real-time CSS 3D orbital halo of 6 tools (Photoshop, Affinity Designer, Canva, CapCut, VSCO, Figma) orbiting in 3D perspective around the portrait.
- **Dynamic Watermark Typography:** Monumental background watermark **Porto** *(bold)* + *Folio* *(cycles through distinct editorial serif italic fonts every 0.8s)*.
- **Editorial Design System:** Custom tokens, warm off-white canvas (`#F7F6F1`), dark mode (`#111210`), and soft lavender-blue atmospheric glow.
- **GPU-Accelerated Scroll Reveals:** Performant, intersection-observer driven reveal animations with staggered cards.
- **Responsive Navigation:** Desktop pill navigation and mobile modal drawer with keyboard accessibility.
- **Light & Dark Themes:** Smooth transition, persistent `localStorage` preference, and zero theme-flash on load.
- **Case Study Ready:** Structured templates for PerdosFit (Double Diamond UI/UX), Website Kelurahan Cantik (Front-End/Gov), and UMKM Lakessi (Visual Branding).

---

## 🛠️ Tech Stack

- **Framework:** React 18
- **Bundler:** Vite 5
- **Routing:** React Router DOM v6
- **Styling:** Vanilla CSS with custom properties & design tokens
- **Icons:** Lucide React
- **Typography:** Instrument Serif, Playfair Display, Bodoni Moda, Cormorant Garamond, Newsreader, DM Sans

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/SaldanRama/SalPorto.git
cd SalPorto
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
